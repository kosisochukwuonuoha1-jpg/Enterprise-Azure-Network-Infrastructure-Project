# Enterprise Azure Network Infrastructure Project

## Project Overview

This project demonstrates the implementation of an enterprise-style Azure network infrastructure environment using Microsoft Azure services.

The objective of this project was to simulate real-world enterprise networking scenarios involving:

- Azure Virtual Machines
- Azure Virtual Networks (VNets)
- Subnet Segmentation
- VNet Peering
- Route Tables
- Azure Network Watcher
- PowerShell Remote Administration
- Connectivity Troubleshooting

---

# Technologies Used

- Microsoft Azure
- Azure Virtual Machines
- Azure Virtual Networks
- Azure Network Watcher
- Route Tables
- Network Security Groups (NSGs)
- PowerShell
- Azure Portal

---

# Solution Architecture

The environment consists of:

- Multiple Azure Virtual Machines
- Multiple VNets
- Subnet segmentation
- Bidirectional VNet Peering
- Custom Route Tables
- Network monitoring and troubleshooting tools

This setup simulates communication between enterprise departments across isolated network environments.

---

# Virtual Machine Deployment

Azure Virtual Machines were deployed to simulate enterprise workloads.

Features implemented:
- Windows Server Virtual Machines
- Resource Group organization
- Network interface configuration
- Remote administration

---

# Virtual Network Configuration

Multiple VNets were configured to establish isolated network environments.

Features implemented:
- Address space configuration
- Subnet segmentation
- Private IP communication

---

# Subnet Segmentation

Subnets were created to logically separate workloads within the virtual network.

Examples:
- Core subnet
- Perimeter subnet

This improves:
- Security
- Traffic management
- Network organization

---

# VNet Peering Configuration

Bidirectional VNet Peering was configured between virtual networks.

This enabled:
- Secure private communication
- Azure backbone connectivity
- Low-latency network communication

---

# Route Table Configuration

Custom Route Tables were implemented to control traffic flow across the network.

Features:
- User Defined Routes (UDRs)
- Custom next-hop configuration
- Traffic routing through virtual appliances

---

# Azure Network Watcher

Azure Network Watcher was used for:

- Connectivity troubleshooting
- NSG diagnostics
- Next-hop analysis
- Network monitoring

This helped validate communication paths between Azure resources.

---

# PowerShell Remote Administration

Azure Run Command and PowerShell were used to perform remote administration tasks.

Tasks performed:
- Connectivity testing
- Remote PowerShell execution
- Network validation
